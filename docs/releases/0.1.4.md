# Service Discovery 0.1.4

Fixes Plex health status and returning to the full federation service list.

- Use each service’s registered health endpoint before falling back to its browser address. Plex uses its identity endpoint instead of the authenticated root page.
- Fix native HTTP requests being blocked by conflicting macOS transport settings. HTTPS certificate validation remains enabled.
- Restore the All services sidebar selection and add an All services toolbar button while viewing one system.
- Include the native JSON inspector: summary fields, expandable objects and arrays, search, formatted text, copy controls, and configurable automatic refresh.
- Include per-node health checks, the persistent menu bar app, and Start at Login controls.

Developer ID signed and notarized for direct download. Requires macOS 14 or later on Apple silicon.
