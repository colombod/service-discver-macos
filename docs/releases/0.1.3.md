# Service Discovery 0.1.3

Adds a native JSON inspector for API and status services, including Context Intelligence.

- Expand nested objects and arrays, search keys and values, and inspect formatted JSON.
- See summary fields, HTTP status, payload size, and the last refresh time.
- Copy JSON or individual scalar values and paths.
- Honor each service’s configured refresh interval, with a pause control.
- Recognize JSON response content types in Auto mode and retain Web mode for sign-in.
- Reuse existing service web cookies within their host/path/HTTPS boundaries, without forwarding directory credentials.

Failed refreshes keep the previous successful response visible. Large or deeply nested responses show an explanation instead of overwhelming the viewer. Existing menu bar, login startup, and per-node health improvements remain included.
