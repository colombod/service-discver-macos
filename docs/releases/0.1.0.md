# Service Discovery 0.1.0

Initial macOS client for federated Service Directory systems.

- Browse and search hosted services by system.
- Open services with persistent in-app website sessions or use the default browser.
- Save directory credentials in Keychain.
- Configure SSH and tmux shortcuts per system.
- Detect the optional directory maintenance API.
- Check for signed app updates through Sparkle.

Requires macOS 14+ on Apple silicon and network access to the directory. Hosted services control their own session expiration and login requirements. Remote directory updates require the backend maintenance change and a supported Linux systemd/uv installation; existing nodes are not automatically modified.
